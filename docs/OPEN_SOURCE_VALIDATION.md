## 已知限制

- 这是开发中的本地 MVP，不是已经运营的商业 SaaS。
- 本次未验证真实 AI 供应商、真实生成质量、外部图片/研究 Provider、S3、生产认证代理或支付。支付适配仍是 Mock / unavailable。
- 部分完整 V2 工作流 / 高级导出受特性开关、质量检查和应用套餐逻辑约束；本次没有关闭这些生产限制来宣称商业可用。补充 HTTP 使用显式测试环境，实际 PDF/PNG 直接验证本地渲染入口。
- 既有文档中的“已通过”属于原开发记录；是否属于本次新验证，以此表和 `verification/` 中记录为准。
- Linux/macOS 的完整后端未实测。Pages 只复制静态文件，不能由此推断 Linux 后端成功。
- GitHub 公开目录不含原私人 `.data`、运行稿件、完整参考文本或受限参考素材；原项目暂不可删除。
