# AIPPT 项目简版说明｜Fast Build

## 产品

AIPPT 是一个面向中国大陆用户的 AI 演示工作台。用户输入主题或上传资料后，智能体先理解任务并规划演示，再生成可在线编辑的 PPT，用户可以继续修改并导出。

## 当前唯一核心闭环

```text
主题/资料
→ 最多 3 个关键问题
→ 演示蓝图
→ 5 页标准 16:9 演示
→ 手动编辑
→ AI 只修改指定页面
→ 自动保存 / Undo
→ PPTX / PDF / PNG
```

## 智能体第一版

只做五个阶段：

1. 理解目标、听众和使用场景；
2. 提取资料中的事实、数字、图片与来源；
3. 生成核心主张、章节和逐页目的；
4. 选择简单模板并生成页面内容；
5. 检查明显问题并支持局部修改。

必须做到：不编造关键数据；不越过用户指定的修改范围；真实模型可完成一次完整流程；Mock 只用于测试。

## MVP 页面

- 营销首页；
- 创建中心；
- 演示蓝图；
- Agent Studio；
- 编辑器；
- 质量与交付；
- 项目列表。

## 技术简化

```text
apps/web
apps/api
apps/worker
packages/core
```

推荐：TypeScript、React/Next.js、PostgreSQL、简单任务队列、S3 兼容对象存储、PptxGenJS、Playwright/Chromium、一个主模型和一个可选备用模型。

第一阶段不建设多人协作、模板商城、企业 SSO、多云、私有化、复杂自由画布、完整四种输出、几十个 Agent 节点或大规模评测平台。
